# universal-notes-organizer-26493-26559

This workspace contains the Flutter mobile/desktop frontend "Ocean Notes" (notes_app_frontend). It implements a modern notes UI with:
- Ocean Professional theme (blue & amber)
- List/grid view, categories side menu
- Note details/edit with color and pinned support
- Local SQLite (sqflite) data service with CRUD and seed data

Navigate into notes_app_frontend and run:
- flutter pub get
- flutter run
